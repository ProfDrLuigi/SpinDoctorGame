05 / The project

Original data.
A fresh perspective.

Spin Doctor is being rebuilt for today’s Macs from the original 68k/PowerPC game. Original level data, artwork, programs, and reference recordings form the foundation of the Swift port.

The goal is to preserve the feel of the original. All 106 levels and their goals are implemented, with timing, rendering, and audio still being checked against the classic game.

One more question?

A few things worth knowing.

Spin Doctor is a native macOS app for Apple Silicon and Intel. This website is a showcase of the project. You’ll find the source code and project documentation on GitHub.

All 106 levels are implemented. The reconstruction uses original data, analyzed program code, screenshots, and recordings of the classic game. Full timing, visual, and audio parity is still being evaluated. The repository documents the current status.

The Swift port saves ongoing games in its own .spindoctor format. Load a file using “Open…” and press P to resume. Saved games from the classic Macintosh version cannot be imported.
